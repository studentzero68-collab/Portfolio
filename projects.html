Weather App React

React Vite API Hooks

A React weather experience built around a searchable city input, live API data, loading states, and clear error handling.

What I learned

Challenge: Turning a weather search into a reliable React app without overcomplicating the UI. The goal was to fetch live data, manage loading and error states, and keep the experience understandable for a first-time user.

Outcome: This project strengthened my confidence in React fundamentals — state flow, reusable hooks, and component responsibility. It also showed me how a polished interface can still stay lightweight when the data flow is well organised.

Shopping Center

React Context API Router Cart Logic

A multi-page shopping experience featuring product discovery, shared cart state, filters, pagination, and a checkout flow.

What I learned

Challenge: Managing state across a larger React app without letting the cart or product logic become tangled. The app needed to share data between the navbar, product feed, and checkout experience while still feeling responsive.

Approach: I used two React context providers to share product and cart state across the interface, then connected the UI to a real product feed with fallback data for reliability. The product list supports search, category filtering, pagination, and a full checkout flow that calculates totals, VAT, and delivery costs.

Outcome: This project gave me a much stronger grasp of shared state patterns in React. I learned how to keep data flowing predictably across components, especially when the same information needs to appear in multiple places at once.
