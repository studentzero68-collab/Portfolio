# Mukelani Portfolio

A frontend-only React portfolio for Mukelani Nkazimulo Sindana.

## Structure

- `frontend/`: Vite React application, reusable components, pages, styles, static project data, and public assets.
- `legacy-static/`: preserved pre-React HTML, JavaScript, CSS, and asset copies for reference.

## Development

1. Run `npm install` in the repository root.
2. Start the React app with `npm run dev`.

The Vite development server runs on `http://localhost:5173`.

For production, run `npm run build` followed by `npm --prefix frontend run preview`.
